# 홍천 열목어마을 공식 홈페이지

첨부 목업의 자연스럽고 고급스러운 분위기를 기준으로 제작한 Next.js App Router 기반 반응형 홈페이지입니다. 개인 방문객의 숙소·프로그램 탐색과 기업·기관·학교의 단체 견적 문의를 핵심 전환으로 설계했습니다.

## 실행 방법

Node.js 22.13 이상에서 다음 명령을 사용합니다.

```bash
npm install
npm run dev
```

프로덕션 확인:

```bash
npm run lint
npm run build
```

## 주요 경로

- `/` 홈
- `/village` 마을 이야기
- `/programs` 치유 프로그램
- `/programs/[slug]` 프로그램 상세 4종
- `/stay` 숙소
- `/group` 단체·워크숍
- `/guide` 여행 안내
- `/market` 마을장터
- `/stories` 소식·후기
- `/contact` 예약·문의
- `/privacy`, `/terms` 정책 검토 페이지

## 운영자가 수정할 파일

- `data/site.ts`: 프로그램, 숙소, 일정, 후기, 보도, FAQ, 연락처, 주소, SNS, 예약 링크, 상품, 이미지 출처
- `app/globals.css`: 색상, 글자, 간격, 반응형 디자인
- `public/images/`: 홈페이지 이미지
- `Concept.md`: 사이트 목적과 전환 흐름
- `Design.md`: 디자인 시스템과 반응형 규칙
- `ToDo.md`: 임시 데이터와 운영 준비 목록

`data/site.ts`의 빈 연락처 값은 운영자가 확인한 실제 정보로만 교체하세요. 객실 요금, 환불 기준, 단체 최대 인원, 후기, 상품 가격도 확정 전까지 임의로 입력하지 않습니다.

## 이미지 출처

사이트 사진은 홍천농촌문화터미널 홍천애홀릭의 열목어마을 프로그램 소개 페이지에서 확인한 실제 마을 사진을 개발 시안에 사용했습니다.

- [열목어마을에서 자발적인 산촌유배](https://www.hcholic.com/219)

공개 운영 전 각 이미지의 홈페이지 재사용 권한과 고해상도 원본을 운영자에게 확인하세요. 제공된 목업 이미지는 디자인 비교용으로만 확인했으며 배포 자산에는 포함하지 않았습니다.

## 문의 폼 상태

현재 문의 폼은 백엔드가 연결되지 않은 개발 상태입니다. 제출 버튼을 누르면 정보가 전송되지 않았다는 안내만 표시합니다. 실제 운영 전 다음 중 하나를 연결해야 합니다.

- 운영자 이메일 기반 전송
- 외부 신청 폼
- 별도 예약·문의 백엔드

## SEO

페이지별 title/description/canonical, Open Graph 기본 정보, `sitemap.xml`, `robots.txt`, Organization·LocalBusiness·LodgingBusiness·TouristAttraction 구조화 데이터를 포함합니다. 실제 전화번호와 운영시간은 확정 후 구조화 데이터에도 추가하세요.
